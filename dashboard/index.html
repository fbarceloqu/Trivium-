Falta la configuración de Firebase

Para conectar el panel a tu proyecto:

  1. En la consola de Firebase: ⚙️ Configuración del proyecto → Tus apps → Agregar app → Web (</>). Regístrala (sin Hosting).
  2. Copia el objeto firebaseConfig que te muestra.
  3. En la carpeta dashboard/, copia firebase-config.example.js como firebase-config.js y pega ahí tus valores.
  4. Recarga esta página.
