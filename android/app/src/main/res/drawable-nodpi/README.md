# Imágenes de vocabulario

Aquí van las imágenes generadas con el prompt #2 de `docs/GEMINI_PROMPTS.md`.

**`drawable-nodpi`** es una carpeta especial de Android: las imágenes de aquí
se muestran al mismo tamaño en cualquier tablet, sin que el sistema las
reescale según la densidad de pantalla — ideal para flashcards educativas
donde todas deben verse igual de nítidas y del mismo tamaño relativo.

## Reglas de nombre de archivo (importantes)

- Todo en **minúsculas**.
- Sin espacios: usa **guion bajo** (`_`) en vez de espacio.
  - `ice_cream.webp` ✅ &nbsp; `Ice Cream.webp` ❌
- Solo letras, números y `_` (nada de acentos, ñ, signos).
- Formato: `.webp` o `.png`.
- El nombre debe ser la **palabra en inglés** tal cual aparece en la lista del
  prompt 2 (p. ej. la palabra "police officer" → archivo `police_officer.webp`).

## Ejemplos correctos
```
elephant.webp
ice_cream.webp
hot_dog.webp
police_officer.webp
```
